# 메아리셋 다이어리 → 비서앱 적용안 (2026-05-31)

## 📌 메아리셋 핵심 (확인된 정보)

| 항목 | 내용 |
|---|---|
| 형태 | 종이 다이어리 (3개월 만년형) |
| 가격 | 29,000원 |
| 시즌 | Season 1~4 (각 90일) |
| 핵심 시스템 | **뇌과학 기반 9단계 습관 시스템** |
| 회고 주기 | **90일 돌아보기** |

> ⚠️ 9단계의 구체적 내용은 비공개 (구매자만 확인). 일반적인 습관형성 모델 + 한국 자기계발 다이어리의 공통 패턴을 기반으로 추정·재구성.

---

## 🎯 핵심 컨셉 (메아리셋의 매력 포인트)

1. **"인생 전부"가 아닌 "90일"** — 1년은 부담스럽지만 90일은 손에 잡힘
2. **시즌제 = 게임처럼 단계** — 끝나면 새로 시작하는 리셋감
3. **9단계 = 명확한 로드맵** — "오늘 뭐할지" 막막함 제거
4. **돌아보기 = 회고 강제** — 다음 시즌 더 잘하게 만듦
5. **함께 도전 = 외로움 해소** — 혼자 결심하면 작심삼일

## 💡 한나 비서앱에 적용할 5가지

### 1️⃣ **90일 시즌 시스템** ⭐⭐⭐ (가장 유용)

**현재 비서앱**: 만다라트, 비전보드는 있지만 "기간"이 없음. 끝이 없어서 동기 약함.

**적용안**: 
- 비전보드/만다라트에 **"시즌"** 개념 추가 (90일 단위)
- 시즌 시작 시 4개 카테고리(자기개발/소설가/투자자/가족)별 목표 1-3개 입력
- 헤더에 **"Season 2 · D-43 (47일 남음)"** 표시
- 시즌 종료 자동 알림 → 회고 화면 → 다음 시즌 자동 안내

**한나 맞춤 변형**:
- 시즌 이름을 한나 스타일로 (예: "여름의 시즌 — 소설 완성하기")
- 카테고리별 목표가 만다라트와 자동 연결

---

### 2️⃣ **9단계 진행률 시각화** ⭐⭐

**현재**: 루틴 달성률은 있지만 "큰 목표 → 작은 단계" 분해가 없음

**적용안**: 시즌 목표 입력 시 **9단계 분해 도우미** 제공
```
목표: 소설 한 권 완성 (90일)
↓ 자동 9단계 분해
1. 컨셉/시놉시스 작성     (1-10일)
2. 캐릭터·세계관 정리      (11-20일)
3. 챕터 구조 잡기          (21-30일)
4. 1막 초고                (31-40일)
...
9. 퇴고 + 마무리           (81-90일)
```
- 각 단계 완료 시 체크
- 진행률 = 단계 완료 비율
- 만다라트 중앙 목표와 연결

**구현 위치**: 새 탭 **🌱 시즌**

---

### 3️⃣ **90일 돌아보기 (자동 회고)** ⭐⭐⭐

**현재**: 매일 반성은 있지만 **장기 회고는 없음**

**적용안**: 시즌 종료 D-1일에 회고 카드 자동 생성
- 📊 데이터 자동 집계:
  - 루틴 달성률 (시즌 전체)
  - 카테고리별 시간 (시즌 전체)
  - 완료한 책 / 영화 / 작성한 메모·습작 수
  - 가장 자주 한 루틴 TOP 3
  - 가장 좋았던 감사일기 (랜덤 1개)
- 📝 한나가 직접 답할 질문 3가지:
  - 가장 잘한 것?
  - 가장 아쉬운 것?
  - 다음 시즌에 바꾸고 싶은 것?
- 다음 시즌 목표로 자동 이월/제거 선택

**위치**: 시즌 탭 안 or 반성 탭에 새 카드

---

### 4️⃣ **하루 시작 의식 ("오늘의 한 줄")** ⭐

**현재**: 오늘일정만 있고 "감정 워밍업" 없음

**적용안**: 오늘일정 최상단에 **"오늘 시작하는 한 줄"** 카드
- 매일 아침 첫 접속 시 작성 안내
- 예: "오늘은 소설 챕터 3을 끝내는 게 목표"
- 저녁 반성 시 자동으로 "오늘 한 줄"과 비교 → "달성/미달성"

**메아리셋 영향**: 의도 설정 → 실행 → 회고 사이클

---

### 5️⃣ **커뮤니티 → 솔로 버전 "응원 메시지"** ⭐ (선택)

**현재**: 혼자 사용

**적용안 (가벼운 버전)**: 
- 시즌 시작·중간·종료 시 자동 응원 메시지 카드
- "Season 2 D-30! 이제 한 달 지났어요. 처음 마음 어땠나요? 👇 [회고]"
- 한나가 가족·친구에게 시즌 결과 공유하는 기능 (선택)

**한나에게 더 맞는 변형**:
- "미래의 나" 탭과 연동 → 시즌 끝나는 미래의 나에게 편지
