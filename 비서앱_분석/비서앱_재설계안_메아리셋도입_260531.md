# 비서앱 재설계안: 메아리셋 시스템 도입 (2026-05-31)

> **목표**: 현재 21개 탭 비서앱에 메아리셋 시스템(에코 트라이앵글 + 분기/월간/주간/일간 + C/E/O 분류)을 도입하면서 **R.A.S(시선 분산 방지)** 원칙을 지킴.

## 📥 도입할 것 (메아리셋 → 비서앱)

### 1. 🔺 **에코 트라이앵글 탭** (신규, 최우선)
**메아리셋 챕터**: 7(주단위 청킹), 3(목표-경사), 6(R.A.S)

**구조**:
```
🔴 중심: 핵심 목표 1개 (예: "앞으로 1년")
🟠 Big Echo 3 (큰 방향)
🟢 Small Echo 9 (Big Echo당 3개)
🔵 Action Waves 36 (Small Echo당 4개)
```

**기능**:
- 삼각형 시각화 (SVG로 구현)
- 각 Action Wave 체크박스
- 진행률 자동 계산
- 기존 "만다라트" 탭 **대체**

---

### 2. 📊 **분기 관제탑** (신규)
**메아리셋 챕터**: 4(새출발), 7(청킹)

**구조** (90일 = 분기):
```
📌 못 이룬 목표 Big3 (지난 분기 회고)
   └─ 실패 이유 분석
📌 고칠 나쁜습관 → 대체할 작은 행동
📌 앞으로 Big Echo 3 + Small Echo 9
📌 분기 우선 5가지 (식습관/관계/체력/경제/배움)
```

**자동 알림**:
- 분기 시작 D-3 → "다음 분기 계획 시작 시간!"
- 분기 종료 D-1 → "분기 회고 시간!"

---

### 3. 📅 **월간 관제탑** (신규)
**메아리셋 챕터**: 4(새출발), 7(청킹)

**구조** (W1~W5):
- W1~W4: 주차별 핵심 행동
- W5(또는 마지막주): Small Echo 재설정

**자동 알림**:
- 매월 1일 → "이번 달 계획 세우기"
- 마지막 주 → "Small Echo 점검"

---

### 4. ✅ **C/E/O 일일 분류** (오늘일정 탭에 통합)
**메아리셋 챕터**: 9(인지오프로딩), 1(자이가르닉)

**구조** (요일별 매일):
```
C (Core)      🔴 꼭 해야 할 일 (3개)
E (Execution) 🟢 해두면 좋은 일 (3개)
O (Offload)   🟡 비워낼 일 (나에게 부담만 됐던 것)
```

**적용**:
- 오늘일정 탭에 C/E/O 카드 추가
- 각 항목 체크 후 → 주간 자동 회고에 반영
- 할일 추가 시 C/E/O 선택 옵션

---

### 5. 📝 **주간 회고** (반성 탭에 통합)
**메아리셋 챕터**: 4(새출발), 2(에빙하우스)

**핵심 질문**:
> "이번 주, 예상 밖으로 잘한 1가지는?"

**구조**:
- 매주 일요일 저녁 자동 알림
- 이번 주 데이터 자동 집계 (루틴 달성률, 시간 통계, 완료한 책 등)
- 한나가 자유롭게 회고 작성
- 다음 주 Small Echo 자동 안내

---

### 6. 💌 **나에게 편지** (미래의 나 탭 강화)
**메아리셋 챕터**: 2(에빙하우스), 4(새출발)

**기능**:
- 편지 쓰기: "지금 가장 뜨거운 결심을 90일 뒤 나에게"
- 봉인 (지정 기간 동안 못 봄)
- 기간 옵션: **30일 / 90일 / 1년**
- 도착 시 알림 + 시즌 회고와 연동
- 알림: "편지 쓸 시간!" (시즌 시작 시)

---

### 7. 🔔 **수시 동기부여 팝업**
**메아리셋 챕터**: 6(R.A.S), 4(새출발), 1(자이가르닉)

**작동**:
- 매일 1-2회 무작위 시간 (or 사용자 설정 시간)
- 9챕터 원리 기반 메시지 풀
- 시즌·주간 진행률에 따라 동적 메시지

**예시**:
- "Big Echo 1까지 73% 왔어요! 마지막 27%는 시작이 반이에요" (목표경사)
- "오늘 시작한 루틴 3개 중 1개가 미완료예요" (자이가르닉)
- "월요일이에요. 이번 주 Small Echo는 뭘로 정하실래요?" (새출발)
- "1년 전 오늘 한나가 쓴 감사일기: [내용]" (에빙하우스)

---

### 8. 🧠 **브레인 덤프** (메모 탭 강화)
**메아리셋 챕터**: 8(브레인 덤프), 9(인지오프로딩)

**기능**:
- 메모 탭에 "🧠 브레인 덤프 모드" 추가
- 분류 없이 자유 입력 (음성 메모 포함)
- 나중에 할일/걱정/아이디어/메모로 분류
- 걱정제거 탭과 연결

[ 기록 ]

   🧠 메모/브레인 덤프
   📅 캘린더

[ 창작 ]
   📝 습작
   ✍️ 단편소설
   💬 문장수집

[ 자기탐색 ]
