**지금 상태**: 기능은 풍부함(21개 탭). 하지만 **(1) 단일 파일 9,571줄로 너무 큼**, **(2) 자동 백업 없음 → 데이터 분실 위험**, **(3) 매일 안 쓰는 탭이 많아 화면이 무거움**.

**가장 시급한 3가지**:
1. 🚨 **자동 백업** — 폰 캐시 날아가면 모든 기록 사라짐
2. 🎯 **홈 위젯/요약 카드** — 21개 탭을 다 안 봐도 되게
3. ⏰ **루틴 알림** — 타이머 멈추기/시작하기 깜빡함 방지

## ✅ 장점

1. **한나 맞춤형 카테고리** (자기개발/소설가/투자자/가족) — 정체성과 일치
2. **풍부한 기능** — 일정·루틴·창작·건강·반성까지 한 번에
3. **타이머 + 시간 통계** — 시각적 타임라인, 카테고리별 그래프
4. **구글 캘린더 연동 + 검색** — 외부 일정도 한 화면에서
5. **카테고리 색상 일관성** — 루틴·독서 색이 같아 직관적
6. **빠른 배포** — vercel로 폰에서 바로 사용
7. **드래그 탭 정렬, 모달, 자동저장** 등 디테일 좋음

## ❌ 단점

### 데이터 안전성 (최우선)
1. **자동 백업 없음** — localStorage만 쓰면 폰 캐시 지우거나 브라우저 데이터 삭제 시 **전부 사라짐**
2. **백업 알림 없음** — "한 달 안 했어요" 같은 경고가 없음

### UX
3. **탭 21개 = 인지 부하** — 매일 쓰는 건 5-7개, 나머지는 가끔. 가로 스크롤로 찾기 힘듦
4. **홈 화면이 일정만** — 하루를 한눈에 못 봄 (루틴 진행률, 원씽, 감사일기 작성 여부 등)
5. **알림 없음** — 루틴 시간 됐는데 알림이 없으니 잊음
6. **검색이 약함** — 메모/습작/책 내부 키워드 검색 안 됨 (구글 캘린더만 검색됨)

### 유지보수
7. **단일 파일 9,571줄** — 작은 수정에도 전체 파일 업로드, 디버깅 어려움
8. **데이터 레이어 산재** — `load()`/`save()`가 여기저기 흩어져 있어 변경 시 추적 어려움
9. **버그 위험** — 변수명 충돌(`addRoutineSession`, `routineLog` 등) 추적 어려움

### 성능 (미래)
10. **데이터 누적 시 느려짐** — 1년 후 `routineLog` 수천 건. 매번 전체 로드/필터
11. **localStorage 5MB 제한** — 사진 첨부 늘면 한계 도달

### 기능
12. **인사이트 부족** — 시간만 쌓이고 "이번 달 글쓰기 -30%" 같은 통찰 없음
13. **사용 통계 없음** — 어떤 탭이 죽었는지 모름 → 탭 정리 결정 못 함
14. **습작 vs 단편소설 모호** — 사용자가 어디에 쓸지 헷갈릴 가능성

## 🚀 개선 계획 (4단계)

### Phase 1: 안전망 (1-2일, 최우선)
> **목표**: 데이터 분실 위험 0%로

1. **자동 백업**
   - 매일 자정 첫 접속 시 구글시트로 자동 push
   - 백업 시각을 헤더에 작게 표시 ("마지막 백업: 3시간 전")
2. **백업 경고**
   - 7일 이상 백업 안 됐으면 빨간 배너로 경고
3. **JSON export 단축버튼**
   - 설정에서 한 번에 다운로드

**예상 효과**: 폰 바꿔도, 데이터 날아가도 복구 가능

---

### Phase 2: 홈 화면 정리 (3-5일)
> **목표**: 매일 보는 게 한 화면에 다 들어오게

1. **오늘일정 탭 상단에 "오늘의 요약 카드" 추가**
   - 루틴 진행률 (예: 5/8 완료)
   - 원씽 1개
   - 감사일기 작성 여부 (안 했으면 +버튼)
   - 어제 반성 "내일 할 것" (이미 있음)
2. **탭 그룹화** (선택)
   - 자주 쓰는 5-7개만 보이고, 나머지는 "더보기" 메뉴로
   - 30일 안 들어간 탭 자동 숨김 제안
3. **글로벌 검색바**
   - 메모·습작·책·문장수집 통합 검색

**예상 효과**: 매일 탭을 5번 누를 일이 1번으로

---

### Phase 3: 알림 & 인사이트 (1주)
> **목표**: 앱이 먼저 말 걸어주게

1. **루틴 알림** (브라우저 Notification API)
   - 루틴 시간 됐을 때 알림
   - 타이머 진행 중 1시간 넘으면 "아직 진행 중?" 알림
2. **주간 인사이트 카드**
   - 매주 일요일 자동 생성: "이번 주 글쓰기 +30%, 운동 -20%"
   - 카테고리별 시간 비교
3. **습관 잔디** (GitHub 스타일 캘린더)
   - 365일 칸이 채워지는 시각화

**예상 효과**: 동기부여 ↑, 객관적 자기인식

---

### Phase 4: 구조 개선 (필요 시, 점진적)
> **목표**: 유지보수 쉽게, 미래 확장 가능하게

1. **파일 분리** (단계적)
   - HTML / CSS / JS 분리
   - JS는 모듈별 (routine.js, book.js, calendar.js…)
2. **데이터 레이어 정리**
   - `getXXX()`/`saveXXX()` 패턴 통일
   - 단일 진실 소스(single source of truth)
3. **IndexedDB 이전** (데이터가 5MB 가까워질 때)
4. **사용 통계 수집** — 어떤 탭이 죽었는지 데이터로 확인 후 정리

**예상 효과**: 새 기능 추가/버그 수정 속도 2-3배
