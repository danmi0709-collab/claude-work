⚙️ Client ID 설정 (처음 한 번만)

구글 캘린더를 사용하려면 아래 단계가 필요해요:

1. console.cloud.google.com 접속
2. 새 프로젝트 생성 → Google Calendar API 활성화
3. 사용자 인증 정보 → OAuth 클라이언트 ID 생성
   (웹 애플리케이션 선택, 승인된 출처에 null 또는 file:// 추가)

💾 로컬 백업 (파일로 저장/불러오기)
⚙️ Apps Script 설정 방법
1. 구글 시트 새로 만들기
2. 상단 메뉴 → 확장 프로그램 → Apps Script
3. 비서앱_동기화_스크립트.gs 파일의 내용 붙여넣기
4. 저장 후 → 배포 → 새 배포
5. 유형: 웹 앱, 액세스: 모든 사용자 선택 후 배포
6. 생성된 URL을 위 입력창에 붙여넣고 URL 저장
