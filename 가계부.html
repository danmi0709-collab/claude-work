📋 구글 시트 연동 설정 방법
  1. 구글 시트를 하나 새로 만드세요.
  2. 상단 메뉴 → 확장 프로그램 → Apps Script 클릭
  3. 기존 내용 지우고 구글시트_스크립트.gs 파일의 내용을 붙여넣기
  4. 저장(💾) 후 → 배포 → 새 배포 클릭
  5. 유형: 웹 앱, 액세스: 모든 사용자 선택 후 배포
  6. 생성된 URL을 위 입력창에 붙여넣고 URL 저장

· PC에서 입력 후 → PC→폰 올리기
· 저장할 때마다 구글 시트에 자동 백업됩니다.
