# 금지 표현 목록 (AI 냄새 제거)

## 어디서든 쓰지 말 것

| 금지 표현 | 대신 이렇게 |
|----------|------------|
| "다양한" | 구체적으로 몇 가지인지 써라 |
| "효과적으로" | 뭐가 어떻게 좋은지 써라 |
| "혁신적인", "획기적인" | 근거 없는 과장. 쓰지 마 |
| "~에 대해 알아보겠습니다" | 바로 본론으로 시작해 |
| "마무리하며", "결론적으로" | 마지막 내용 그냥 쓰고 끝내 |
| "중요합니다", "필수입니다" | 왜 중요한지 써라 |
| "~의 세계" | 진부한 표현. 쓰지 마 |
| "함께 알아보아요" | AI 냄새 1등 표현 |
| "오늘은 ~에 대해" | 블로그 서론 클리셰 |
| "첫째, 둘째, 셋째" (매번) | 가끔만. 매번은 기계적 |

## 소설 쓸 때 특히 금지

| 금지 | 이유 |
|------|------|
| "그의 눈이 빛났다" | 진부한 감정 묘사 |
| "심장이 쿵 내려앉았다" | 클리셰 |
| "말문이 막혔다" | 너무 많이 쓰인 표현 |
| "믿을 수 없었다" | 보여주지 않고 설명만 함 |
| 감탄사 남발 ("아!", "오!", "세상에!") | 직접 감정 전달 대신 상황으로 보여줄 것 |
| 날씨로 감정 암시 (비 = 슬픔) | 너무 뻔함 |

## 인스타 카피 쓸 때 특히 금지

| 금지 | 이유 |
|------|------|
| "저도 처음엔 몰랐어요" | 과장된 공감 클리셰 |
| "이것 하나로 바뀌었어요" | 낚시성 문구 |
| "꼭 필요한 분들을 위해" | 뻔한 마무리 |
| 이모지 3개 이상 연속 | 산만함 |
| "공감되시면 저장해두세요" | 강요하는 느낌 |

---

## 글 쓸 때 원칙

1. 한 문장 = 하나의 정보
2. 서론 없이 바로 본론
3. "~입니다" 연속 3번 이상 금지 (문장 끝 다양하게)
4. 독자가 실제로 쓸 수 있는 내용만
