# 한나의 비서앱 — 데이터 동기화 설정

## 구조

```
폰 → 시트에 올리기 → Vercel API(/api/sync) → Apps Script(POST) → 저장
PC → 시트에서 가져오기 → Apps Script(GET, JSONP) → 폰 데이터 불러옴
```

---

## Apps Script 전체 코드 (업데이트 시 통째로 교체)

```javascript
// ======================================================
// 한나의 비서앱 - 데이터 동기화 Apps Script
// ======================================================

const PROP_PREFIX = 'BISSA_';
const SYNC_KEYS = ['todos','routines','catNames','books','hallOfFame','memos','movies','stories','gratitude','sleepLog','phoneUsage','moods','drafts','selfSnapshots','futureMe','futureAdvices'];

function doGet(e) {
  var callback = e.parameter.callback;
  var props = PropertiesService.getScriptProperties();
  var data = {};
  SYNC_KEYS.forEach(function(key) {
    var val = props.getProperty(PROP_PREFIX + key);
    if (val) { try { data[key] = JSON.parse(val); } catch(err) {} }
  });
  var json = JSON.stringify(data);
  if (callback) return ContentService.createTextOutput(callback + '(' + json + ')').setMimeType(ContentService.MimeType.JAVASCRIPT);
  return ContentService.createTextOutput(json).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var body = JSON.parse(e.postData.contents);
    var props = PropertiesService.getScriptProperties();
    if (body.action === 'set') {
      SYNC_KEYS.forEach(function(key) {
        if (body.data[key] !== undefined) {
          props.setProperty(PROP_PREFIX + key, JSON.stringify(body.data[key]));
        }
      });
      return ContentService.createTextOutput(JSON.stringify({status:'ok'})).setMimeType(ContentService.MimeType.JSON);
    }
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status:'error',message:err.message})).setMimeType(ContentService.MimeType.JSON);
  }
}
```

## Apps Script 배포 방법

1. 구글 시트 열기
2. 확장 프로그램 → Apps Script
3. 위 코드 전체 붙여넣기 → 저장(Ctrl+S)
4. 배포 → 배포 관리 → 새 버전 → 배포
5. 액세스 권한: **모든 사용자** / 실행: **나(본인)**

---

## 동기화 순서

1. **폰** → 캘린더 탭 → 데이터 동기화 → **시트에 올리기**
2. **PC** → 캘린더 탭 → 데이터 동기화 → **시트에서 가져오기**
