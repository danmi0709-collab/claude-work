# 부동산 작업 전용 규칙

> 이 폴더에서 작업할 때는 이 규칙이 글로벌 CLAUDE.md보다 우선합니다.

## 필수 참조
- 작업 전 `TEMPLATES/부동산분석-템플릿.md` 확인

## 출력 규칙
- 숫자와 근거 중심으로 작성
- 의견은 "결론" 항목에만
- 표 적극 활용 (단지 비교, 시세 등)
- 추측은 "추정" "예상" 명시, 확인된 수치와 구분

## 시세 관련
- 실거래가 기준으로 작성 (호가 아님)
- 날짜 반드시 명시 (예: 2026년 5월 기준)
- 매매가/전세가/전세가율 세트로 표기

## 결과물 저장
- `../../OUTPUTS/YYYYMMDD_부동산_지역명.md` 형식으로 저장

## 작업 흐름
1. 지역명과 분석 목적 확인 (불명확하면 먼저 질문)
2. 템플릿 구조대로 작성
3. 파일 저장
