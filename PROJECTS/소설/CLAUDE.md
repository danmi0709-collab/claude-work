# 소설 작업 전용 규칙

> 이 폴더에서 작업할 때는 이 규칙이 글로벌 CLAUDE.md보다 우선합니다.

## 필수 참조
- 작업 전 반드시 `현재소설.md` 읽기
- CONTEXT/anti-ai-style.md 금지 표현 준수 (소설 섹션 특히)

## 문체 규칙
- 감정은 설명하지 말고 행동과 감각으로 보여줄 것
  - ✗ "그녀는 두려웠다"
  - ✓ "그녀는 손잡이에서 손을 떼지 못했다"
- 날씨로 감정 암시 금지 (비 = 슬픔 같은 클리셰)
- 한 문단 = 하나의 장면/감각/생각
- 대화는 인물의 성격이 드러나게

## 분량 기준
- 단편 장면: 400~800자
- 중편 챕터: 1,500~3,000자
- 장편 챕터: 3,000~5,000자

## 결과물 저장
- `../../OUTPUTS/YYYYMMDD_소설_챕터명.md` 형식으로 저장

## 작업 흐름
1. `현재소설.md` 읽기
2. 불명확한 부분 질문 먼저 (한 번에 몰아서)
3. 작성 후 파일 저장
4. 현재소설.md의 진행 상황 업데이트
