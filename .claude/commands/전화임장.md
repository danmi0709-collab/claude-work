전화임장 기록을 분석해서 운영 시트에 자동 입력한다.

인수: $ARGUMENTS (예: `124 그늘` 또는 `124` 또는 비워도 됨)

---

## 0. 인수 파싱

$ARGUMENTS에서 행번호와 닉네임을 추출한다.
- 첫 번째 숫자 = 입력할 행번호
- 두 번째 단어 = 닉네임 (없으면 `그늘` 사용)
- $ARGUMENTS가 비어 있으면 작업 시작 전에 아래 두 가지를 한 번에 물어봐라:
  - "몇 행에 입력할까요?"
  - "닉네임이 뭔가요? (기본: 그늘)"

---

## 1. 파일 자동 탐지

아래 경로에서 파일을 찾는다:
- BASE = `C:\Users\한나\OneDrive\강성업무용\바탕 화면\문서\CLAUDE`
- INPUT = BASE + `\매일전임`  ← 카톡 이미지·음성 파일 보관 폴더
- 스프레드시트 = BASE + `\♡지투실전 28기 15조 운영 시트♡.xlsx`
- 탭명 = `Step3-1. 아맞다 전화임장!`

**이미지 파일 탐지** (매일전임 폴더의 카카오톡 스크린샷):
```
Glob("매일전임/KakaoTalk_*.jpg") → 수정일 기준 최신 순 정렬
```
사용자가 메시지에 이미지를 직접 첨부했다면 그걸 우선 사용.

**음성/텍스트 파일 탐지** (INPUT 폴더):
- 매일전임 폴더의 `.txt` 파일 있으면 바로 Read로 읽기
- 매일전임 폴더의 `.m4a` 파일 있으면 faster-whisper(small 모델, 한국어)로 전사:
```python
from faster_whisper import WhisperModel
model = WhisperModel('small', device='cpu', compute_type='int8')
segments, info = model.transcribe('파일명.m4a', language='ko', beam_size=5, vad_filter=True)
```
- 파일이 여러 개면 수정일 기준 최신 것 사용
- 어떤 파일을 쓸지 불명확하면 사용자에게 한 번에 확인

## 2. 정보 추출

이미지와 통화 내용을 읽고 아래 항목을 정리한다:

| 컬럼 | 내용 | 출처 |
|---|---|---|
| C | 닉네임 | 인수 또는 기본값 `그늘` |
| D | 일자 | 파일명(KakaoTalk_2026MMDD_...) 또는 통화 내용 |
| E | 요일 | 날짜에서 자동 계산 |
| F | 부동산명 | 이미지 중개사 정보 |
| G | 전화번호 | 이미지 중개사 정보 |
| H | 매매 매물수 | 이미지 단지 매물 수 또는 통화 내용 |
| I | 전세 매물수 | 이미지 단지 매물 수 또는 통화 내용 |
| J | 단지명 | 이미지 매물 정보 |
| K | 입주시기 | 이미지 단지 정보 (숫자로: 예 2016.02) |
| L | 세대수 | 이미지 단지 정보 |
| N | 동/층/향 | 이미지 매물 정보 (예: `108동 10~15층 남동향`) |
| O | 공급평형 | 공급면적(㎡) ÷ 3.3 반올림 |
| P | 매매가 | 만원 단위 (예: 26.4억 → 264000) |
| Q | 전세가 | 만원 단위, 없으면 공란 |
| U | 특이사항/전임내용 | 매물 상태, 입주 가능 여부, 세입자 상황 등 |
| V | 부동산 평가 | 사장님 태도, 정보 제공 수준 |
| W | 얻은 정보/내생각 | 인근 단지 비교, 시장 분위기, 투자 인사이트 |

**수식 자동 입력** (M, R, S, T열):
```
M{r} = =year(today())-K{r}+1
R{r} = =if(and(P{r} <> "", Q{r} <> ""), P{r}-Q{r}, "")
S{r} = =if(and(P{r} <> "", O{r} <> ""), P{r}/O{r}, "")
T{r} = =if(and(Q{r} <> "", P{r} <> ""), Q{r}/P{r}, "")
```

## 주의사항
- 정보가 불명확한 컬럼은 공란으로 두고 억지로 채우지 않는다
- 이미지가 여러 장이면 모두 Read로 읽은 후 종합한다
- 통화가 여러 건이면 한 행에 통합해서 입력한다 (단, 다른 단지면 각각 별도 행)
- 날짜는 파일명 기준: `KakaoTalk_20260421_...` → 2026-04-21
- 파일은 항상 매일전임 폴더에 저장: `C:\Users\한나\OneDrive\강성업무용\바탕 화면\문서\CLAUDE\매일전임\`
