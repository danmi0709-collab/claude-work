# 아침 브리핑

오늘 날짜 기준으로 아침 브리핑을 만들어라.

아래 3가지를 동시에(병렬로) 수집해라:

## 1. 오늘 일정
- 캘린더 MCP 도구(list_events)로 오늘 일정 조회
- 캘린더 MCP가 없으면 "캘린더 연결 필요" 라고 표시
- 시간순으로 정리

## 2. 부동산 뉴스
- WebSearch로 오늘 날짜 기준 최신 부동산 뉴스 3개 수집
- 검색어: "부동산 오늘 뉴스"
- 제목 + 한 줄 요약만

## 3. 관심 지역 시세 동향
- WebSearch로 아래 지역 시세 동향 검색
- 관심 지역: 부산 남구, 부산 수영구, 대전 동구, 천안 동남구, 창원 성산구, 송파구
- 검색어: "[지역명] 아파트 시세 최근"
- 각 지역 한 줄 요약

---

## 결과 저장
- 파일명: `OUTPUTS/YYYYMMDD_아침브리핑.md` (오늘 날짜)
- OUTPUTS 폴더가 없으면 만들어라
- 저장 경로: `C:\Users\한나\OneDrive\강성업무용\바탕 화면\문서\CLAUDE\OUTPUTS\`

## 출력 형식
```
# 📋 YYYY년 MM월 DD일 아침 브리핑

## 오늘 일정
- HH:MM 일정내용
- ...

## 부동산 뉴스
1. 제목 — 한 줄 요약
2. ...

## 관심 지역 시세
- 부산 남구: 요약
- 부산 수영구: 요약
- ...
```

파일 저장 후 화면에도 출력해라.
