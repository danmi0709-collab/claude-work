# 메일 정리 및 답장

$ARGUMENTS가 비어 있으면 받은 메일함을 요약해라.
$ARGUMENTS에 내용이 있으면 해당 요청을 처리해라.

---

## 사용 예시
- `/메일` → 오늘 받은 중요 메일 요약
- `/메일 답장 [이름]에게 [내용]` → 답장 초안 작성
- `/메일 미읽음` → 안 읽은 메일 목록

---

## Gmail MCP가 연결된 경우
Gmail MCP 도구를 사용해서:
1. 오늘 받은 메일 중 읽지 않은 것 조회
2. 중요도 순으로 정렬 (보낸 사람, 제목 기준 판단)
3. 각 메일 한 줄 요약

### 답장 요청 시
1. 원본 메일 내용 파악
2. 한나 님 어조에 맞게 (친절하고 간결하게) 답장 초안 작성
3. 초안 보여주고 수정 여부 확인 후 전송

---

## Gmail MCP가 연결 안 된 경우
아래 안내 메시지 출력:

```
Gmail MCP가 아직 연결되어 있지 않습니다.

연결 방법:
1. Google Cloud Console에서 Gmail API 활성화
2. OAuth 클라이언트 ID 발급
3. Claude 설정에 Gmail MCP 추가

연결되기 전까지는 Chrome을 통해 Gmail을 직접 열어드릴 수 있습니다.
Gmail을 열어드릴까요? (네/아니오)
```

"네" 답변 시 Chrome MCP로 Gmail 열기.
