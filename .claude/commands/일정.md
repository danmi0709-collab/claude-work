# 일정 관리

$ARGUMENTS가 비어 있으면 오늘 일정을 보여줘라.
$ARGUMENTS에 내용이 있으면 해당 요청을 처리해라.

---

## 사용 예시
- `/일정` → 오늘 + 이번주 일정 조회
- `/일정 이번주` → 이번주 전체 일정
- `/일정 추가 내일 오후 3시 치과` → 일정 추가
- `/일정 다음달` → 다음달 일정 조회

---

## 처리 방법

### 조회 요청
캘린더 MCP 도구(list_events)로 해당 기간 조회.
결과를 날짜별, 시간순으로 표시.

### 추가 요청
1. 요청 내용에서 날짜/시간/제목 파악
2. 모호한 부분은 먼저 확인 질문
3. 캘린더 MCP 도구(create_event)로 등록
4. 등록 완료 후 확인 메시지

### 캘린더 연결 안 된 경우
"캘린더 MCP가 연결되어 있지 않습니다. /브리핑 또는 직접 캘린더 앱을 확인해 주세요." 라고 안내.

---

## 출력 형식 (조회 시)
```
## 📅 오늘 일정 (YYYY년 MM월 DD일)
- 10:00 병원
- 14:00 미팅

## 이번주 남은 일정
- 내일(N일): ...
- 모레(N일): ...
```
