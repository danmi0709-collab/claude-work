## 주요 기능 요약

### 데이터 동기화 (캘린더 탭)
- Google Apps Script JSONP GET 방식 (file:// CORS 우회)
- URL-safe base64 인코딩: `TextEncoder → btoa → +→- /→_ =제거`
- GAS Properties Service 키별 분리 저장 (9KB 제한 우회)
- SYNC_KEYS: `['todos','routines','catNames','books','hallOfFame','memos','movies','stories','gratitude']`

### 오늘의 원씽
- 루틴에서 ⭐ 누르면 루틴의 카테고리(self/writer/investor/family) → 역할 자동 할당
- catRoleMap: `{ self:'자기계발', writer:'소설가', investor:'투자자', family:'가족' }`

### 하리ort 탭
- ORT 진도표: Level 1 ~ Level 12+, 카테고리별 6권, 3×2 그리드
- 3회독 체크박스
- 책 표지: Open Library fetch + Google Books JSONP 병렬 시도 → localStorage 캐시
- **진행 중:** PDF 차트에서 직접 크롭으로 정확한 표지 교체 작업

### 하리ort 차트 크롭 좌표 (5120×3640 전체 이미지 기준)
- 헤더 높이: y=0~430 (ORT 로고, 타이틀)
- **1행 시작:** y=430
- **행 높이:** 200px (행N 시작 y = 430 + N×200)
- **책 슬롯 x 시작:** x=230 (라벨 컬럼 150px + 서브라벨 80px)
- **슬롯 너비:** 162px (6권: x=230, 392, 554, 716, 878, 1040)
- 행 순서 = ORT_LEVELS 카테고리 순서 그대로
