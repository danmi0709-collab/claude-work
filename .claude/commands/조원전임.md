# 조원전임 메모 추가

사용자가 임장 텍스트를 붙여넣으면, 시세시트에서 해당 단지를 찾아 메모를 추가한다.

## 파일 경로
`C:\Users\한나\OneDrive\강성업무용\바탕 화면\문서\CLAUDE\시세시트_링크추가.xlsx`

## 처리 순서

1. **단지명 추출**: 텍스트 첫 줄에서 단지명 추출 (예: "잠실엘스 2008.09 5678^" → "잠실엘스")
   - 연식(YYYY.MM)과 세대수(숫자^) 패턴 앞까지가 단지명

2. **단지 검색**: 시트 전체(모든 시트, 모든 열)에서 단지명 검색
   - 못 찾으면: 연식·세대수가 일치하는 단지 검색 후 사용자에게 확인

3. **대상 행 결정**: 해당 단지 중 전용면적이 가장 작은 행(가장 위쪽 행)

4. **기존 메모 확인**:
   - 없으면: 새 메모 생성
   - 있으면: 기존 내용 확인 후 오늘 날짜가 이미 있으면 중복 알림, 없으면 `---` 구분선 추가 후 이어붙임

5. **메모 내용 정리**: 원문 그대로 넣지 않고 아래 형식으로 요약·정리
   ```
   한나 [YYYY-MM-DD]
   부동산명 연락처
   매물: XX평(XX㎡) XX동 층 향 / 매 XX억·전 XX억

   [중개사 코멘트]
   - 핵심 내용만 간결하게

   [시장 정보] (있을 경우)
   - 핵심만

   [부동산 평가] 한 줄 요약
   ```
   - 불필요한 줄바꿈·반복 제거
   - ⚠️ 중요 주의사항(법적·자금 리스크 등)은 별도 섹션으로 강조

6. **저장**: 원본 파일 직접 저장 (openpyxl Comment 사용, 작성자 '한나')

7. **완료 후**: git 명령어 안내
   ```
   cd "C:\Users\한나\OneDrive\강성업무용\바탕 화면\문서\CLAUDE"
   git add "시세시트_링크추가.xlsx"
   git commit -m "XX 임장메모 추가"
   git push
   ```

## 주의사항
- 엑셀 파일이 열려 있으면 저장 불가 → 닫아달라고 요청
- 단지명이 애매하면 반드시 사용자에게 확인 후 진행
- 오늘 날짜 메모가 이미 있으면 재추가하지 않고 알림
