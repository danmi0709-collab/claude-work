# 사진 옮겨줘 — 하리가 한 말 앱 사진을 노션으로

「하리가 한 말」 앱에 보관된 사진을 노션 「하리가 한 말」 페이지의 해당 기록 아래로 옮긴다.
사용자가 "사진 옮겨줘", "하리 사진 옮겨줘"라고 해도 이 순서를 따른다.

## 왜 이 작업이 필요한가
앱(claude.ai artifact)은 보안 규칙상 노션 서버로 사진 파일을 직접 보낼 수 없다.
그래서 앱은 글만 노션에 쓰고, 사진은 앱 보관함(assets + db `photos`)에 둔다.
노션 기록에는 `📷 사진 N장은 「하리가 한 말」 앱에 보관` 한 줄이 붙어 있다.

## 고정 정보
- 앱: https://claude.ai/artifact/KjjHpibeMtskSksEtWDJp1
- 노션 페이지 ID: 40e7777c03e9813dbc52e20141216d90
- 필요한 네트워크 허용: api.notion.com (Default 환경에 2026-11-06 추가함)

## 순서
1. **옮길 사진 찾기**: `ArtifactData` list, collection `photos`.
   `movedAt`이 없는 문서만 대상. 각 문서: `assetId`, `tag`(예: `@20261105목 18:11`), `quote`, `createdAt`.
   없으면 "옮길 사진이 없어요"라고 말하고 끝.
2. **노션 페이지 읽기**: `notion-fetch`로 페이지를 읽고, `<b>{tag}</b>`로 시작하는 기록을 찾는다.
   같은 tag가 여러 개면 `quote` 앞부분이 맞는 기록을 고른다. 못 찾으면 사용자에게 물어본다.
3. **사진 내려받기**: `Artifact` read, `url`=앱 주소, `path`=assetId (한 번에 하나씩. `paths`는 실패함).
4. **노션에 올리기**: 사진마다 `notion-create-file-upload`(filename `hari_{날짜시간}_{번호}.jpg`)로 주소를 받고,
   곧바로 Bash에서 `curl -X POST {upload_url} -H "authorization: ..." -F "file=@{파일};type=image/jpeg"`.
   업로드 주소는 몇 분 안에 만료된다. 주소 받기 → 올리기 → 4번 붙이기를 쉬지 말고 이어서 한다.
5. **기록 아래에 붙이기**: `notion-update-page` update_content로
   `<br /><span color="gray">📷 사진 N장은 「하리가 한 말」 앱에 보관</span>\n</p>` 를
   `\n</p>\n\n<image source="file-upload://{id1}" />\n\n<image source="file-upload://{id2}" />` 로 바꾼다.
   사진 순서는 `createdAt` 오름차순.
6. **옮김 표시**: `ArtifactData` batch update로 각 문서에 `movedAt`(현재 시각 ms)을 넣는다 (`if_version` 필수).
   앱 화면의 「노션으로 옮길 사진」 목록에서 빠진다. 앱 보관함의 사진 파일은 지우지 않는다(백업).
7. **확인**: 노션 페이지를 다시 읽어 `<image` 블록이 기록 아래에 들어갔는지 본다.
8. **보고**: 몇 개 기록에서 사진 몇 장을 옮겼는지 한두 줄로.

## 막힐 때
- curl이 403(프록시 거절) → api.notion.com이 환경 허용 목록에 있는지 `get_environment`로 확인.
- `expired` 오류 → 4번부터 새 주소로 다시.
