# 사진 옮겨줘 — 앱에 보관된 사진을 노션으로

「하리가 한 말」 앱과 「성공일기」 앱에 보관된 사진을 노션의 해당 기록 아래로 옮긴다.
사용자가 "사진 옮겨줘"라고 하거나, 매주 일요일 밤 예약 작업이 실행될 때 이 순서를 따른다.

## 왜 필요한가
앱(claude.ai artifact)은 보안 규칙상 노션 서버로 사진 파일을 직접 보낼 수 없다.
그래서 앱은 글만 노션에 쓰고, 사진은 앱 보관함(assets + db `photos` 컬렉션)에 둔다.
노션 기록에는 `<span color="gray">📷 사진 N장은 「…」 앱에 보관</span>` 한 줄이 붙어 있다(없을 수도 있음).

## 대상 앱 (둘 다 처리)
| 앱 | 앱 주소 | 노션 페이지 ID | 사진이 들어갈 곳 |
|---|---|---|---|
| 하리가 한 말 | https://claude.ai/artifact/KjjHpibeMtskSksEtWDJp1 | 40e7777c03e9813dbc52e20141216d90 | `<b>{tag}</b>`로 시작하는 문단 바로 아래 |
| 성공일기 | https://claude.ai/artifact/AbkLaC2XLaT7WxgMTuypRL | 4017777c03e9800d89a1fcb6b0838e8d | 「해냈습니다!」 칸(첫 번째 column)에서 `<b>{tag}<br /></b>`로 시작하는 문단 바로 아래 |

네트워크: api.notion.com 이 Default 환경 허용 목록에 있어야 한다(2026-11-06 추가함).

## 순서 (앱마다)
1. **옮길 사진 찾기**: `ArtifactData` list, collection `photos`. `movedAt`이 없는 문서만.
   필드: `assetId`, `tag`(하리: `@20261105목 18:11`, 성공일기: `@20261105목`), `createdAt`, (하리만) `quote`.
   tag별로 묶고 `createdAt` 오름차순 정렬. 없으면 다음 앱으로.
2. **노션 페이지 읽기**: `notion-fetch`. tag에 맞는 문단을 찾는다.
   하리: 같은 tag가 여러 개면 `quote` 앞부분이 맞는 문단. 성공일기: 반드시 첫 번째 column(해냈습니다!) 안에서만 찾는다.
3. **사진 내려받기**: `Artifact` read, `url`=앱 주소, `path`=assetId. 하나씩(`paths`는 실패함).
4. **노션에 올리기**: 사진마다 `notion-create-file-upload`(filename `hari_…jpg` 또는 `success_…jpg`)로 주소를 받고
   곧바로 Bash: `curl -sS -X POST {upload_url} -H "authorization: {헤더값}" -F "file=@{파일};type=image/jpeg"`.
   응답의 `status`가 `uploaded`인지 확인. 업로드 주소는 몇 분 안에 만료되므로 4→5를 쉬지 말고 이어서 한다.
5. **기록 아래에 붙이기**: `notion-update-page` update_content 한 번에:
   - old_str = 그 문단 전체(`<p color="gray_bg">`부터 `</p>`까지) + 바로 뒤에 이미 있는 `<image …/>` 블록들(있으면)
   - new_str = 같은 문단에서 `<br /><span color="gray">📷 사진 …앱에 보관</span>` 부분만 지운 것
     (문단이 `</b>` 바로 뒤에 그 span만 있는 경우는 span만 지움) + 기존 image 블록들 +
     `\n\n<image source="file-upload://{id}" />` 를 사진 수만큼
   - 맞는 문단이 없으면: 하리는 페이지 끝에, 성공일기는 해냈습니다! 칸 마지막 블록 뒤에
     `<p color="gray_bg">\n<b>{tag}…</b>\n</p>` 문단을 새로 만들고 그 아래에 사진을 붙인다.
6. **옮김 표시**: `ArtifactData` batch update로 각 문서에 `movedAt`(현재 시각 ms). `if_version` 필수.
   앱 화면의 「노션으로 옮길 사진」 목록에서 빠진다. 앱 보관함의 사진 파일은 지우지 않는다(백업).
7. **확인**: 노션 페이지를 다시 읽어 `<image` 블록이 맞는 자리에 들어갔는지 본다.

## 보고
앱별로 "기록 몇 개, 사진 몇 장 옮김" 한두 줄. 옮길 게 없으면 "옮길 사진이 없어요".

## 막힐 때
- curl 403(프록시 거절) → `get_environment`로 api.notion.com 허용 여부 확인. 없으면 사용자에게 알린다.
- `expired` 오류 → 4번부터 새 주소로 다시.
- 한 앱이 실패해도 다른 앱은 계속 처리하고, 실패한 사진은 `movedAt`을 넣지 않는다(다음에 다시 옮겨짐).
