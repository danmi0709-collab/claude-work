파일을 마크다운(.md)으로 변환한다 (MarkItDown 사용)

대상 파일: $ARGUMENTS

## 처리 순서

1. **대상 파일 찾기**
   - $ARGUMENTS에 파일명이 있으면 그 파일을 찾는다 (먼저 `/mnt/attach`, 없으면 리포 안에서 검색).
   - $ARGUMENTS가 비어 있으면 `/mnt/attach` 폴더에서 가장 최근에 올라온 파일을 찾는다.
   - 파일을 못 찾으면 "채팅창에 변환할 파일을 올려주세요" 라고 안내하고 멈춘다.

2. **markitdown 설치 확인**
   - `markitdown --version` 실행
   - 안 되면 `pip install -r requirements-markitdown.txt` 로 설치 후 다시 확인

3. **변환**
   - `markitdown "원본파일" > "OUTPUTS/마크다운변환/원본파일명.md"` 형태로 변환
   - `OUTPUTS/마크다운변환/` 폴더가 없으면 만든다
   - 여러 파일이 대상이면 파일마다 반복

4. **전달**
   - SendUserFile 도구로 변환된 .md 파일을 사용자에게 바로 보낸다

5. **결과 요약 (비전문가 기준, 존댓말, 짧게)**
   - 원본 파일 형식 → 변환 성공/실패
   - 실패했으면 이유를 쉬운 말로 (예: "이 pptx 파일 안의 표가 너무 복잡해서 일부 못 옮겼어요")
   - 영상·음성 파일은 이 환경에 ffmpeg가 없어서 변환 안 됨을 미리 안내

## 주의사항
- 사용자 확인 없이 원본 파일을 삭제하거나 옮기지 않는다
- 변환 결과 .md는 항상 `OUTPUTS/마크다운변환/` 안에 남겨서, 다음에 다시 찾을 수 있게 한다
