## 1. 가장 큰 문제 — `getCategoryGroup` 반복 (속도)

지출 1건이 어느 그룹(고정/변동/교육/비정기)인지 알아낼 때마다
**브라우저 저장소(localStorage)를 통째로 다시 읽고 해석(JSON.parse)** 합니다.

- 내역이 100건이면, 화면 한 번 그릴 때 이 작업이 **수백 번** 반복됩니다.
- 저장 버튼 한 번 → 내역·분석·카테고리 탭이 모두 다시 그려지며 누적됩니다.

**해결:** 연예산 데이터를 한 번 읽어 "항목→그룹" 표를 메모리에 만들어 두고,
데이터가 바뀔 때만 갱신. → 저장소 읽기를 **수백 번 → 1번**으로 줄임.
(내역이 많아질수록 체감 차이가 커집니다.)

## 2. 저장 한 번에 화면 3번 다시 그림 (속도)

`renderAll()`이 내역·분석·카테고리 탭을 한꺼번에 새로 그립니다.
지금 보고 있지 않은 탭까지 매번 그리는 셈입니다.

**해결:** 지금 보이는 탭만 그리고, 나머지는 그 탭을 열 때 그리기.

## 3. 죽은 변수 정리 (청소)

`monthlyChartInstance`, `groupTrendChartInstance` 두 변수가 선언만 되고
어디에도 안 쓰입니다. 예전 차트 기능의 흔적입니다. → 삭제해도 무방.

## 4. 파일 3개 코드 중복 (유지보수)

`가계부.html` / `가계부_공유용.html` / `index.html` 에 거의 같은 코드가 들어 있어,
하나 고치면 셋 다 손봐야 합니다. 지금은 수작업으로 맞추는 중입니다.

**현실적 대안:** 단일 HTML 철학은 유지하되, 공통 코드를 별도 .js 파일로 빼서
세 파일이 같이 불러 쓰게 하면 중복이 사라집니다. (단, 구조 변경이라 시간 듦)
