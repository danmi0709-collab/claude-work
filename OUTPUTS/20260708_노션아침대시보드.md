# 🌅 한나의 아침 대시보드 (노션)

**페이지 주소**: https://app.notion.com/p/3977777c03e980e98ab4d022f3a53e67

## 구성 (데이터베이스 4개 + 관계형 연결)

| 데이터베이스 | 역할 | 주요 기능 |
|---|---|---|
| 📌 할일 | 비서앱 할일 10개 이관 | 날짜·역할·중요(⭐)·완료, 캘린더뷰, 역할별 보드뷰 |
| 🔁 루틴 | 루틴 36개 이관 (진행중 6 / 쉬는중 30) | 역할별 보드뷰, **실천 횟수·달성률 자동 계산**(rollup, 자동 집계) |
| ✅ 루틴 체크 | 매일 실천 기록 | 루틴 DB와 **관계형 연결**(relation), 날짜 캘린더뷰 |
| 🌙 하루 기록 | 아침 일지 | 컨디션·오늘의 원씽·감사한 일·한 줄 정리, 캘린더뷰 |

## 대시보드 첫 화면 순서
1. ① ✅ 오늘 루틴 체크 — 미완료만 필터링
2. ② 📌 남은 할일 — 중요한 것 위로 정렬, 완료 체크하면 사라짐
3. ③ 🌙 하루 기록 — 한 줄 일지
4. 🔥 지금 키우는 루틴 현황 — 달성률 자동 표시
5. 🗓 이번 달 한눈에 — 루틴 실천 캘린더 + 할일 캘린더
6. 🗂 원본 데이터베이스 4개

## 아침 사용법 (3분)
1. 어제 한 루틴에 완료 체크
2. 남은 할일 확인, 끝낸 것 체크
3. 하루 기록에 오늘 한 줄 쓰기
4. 새 날짜 루틴 체크는 "New"로 추가 (이름 예: `7/9 소설쓰기`, 루틴 연결 선택)

## 관계형 연결 작동 방식
루틴 체크에 기록을 쌓으면 → 🔁 루틴 DB의 "실천 횟수"와 "달성률"이 자동으로 올라가요.
뭘 얼마나 했고 뭘 안 했는지 루틴별로 다 보여요.
