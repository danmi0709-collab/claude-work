## 📈 자산 탭 — 순자산 추이 차트 추가

**어디서**: 자산 탭(5번째 탭) 안에 새 섹션 추가

**뭐가 생겼나**
- "이번 달 기록" 버튼 → 누르면 오늘 기준 순자산(자산 − 부채)을 자동 계산해서 저장
- 같은 달에 다시 누르면 덮어씀 (최신 값 유지)
- 2개월 이상 쌓이면 꺾은선 차트(라인차트) 자동 표시
- 차트 아래에 월별 기록 목록 표시 (✕ 누르면 해당 월 삭제)

**사용법**
1. 자산 탭에서 자산/부채 금액을 최신으로 업데이트
2. "이번 달 기록" 버튼 클릭
3. 매월 반복하면 순자산 변화를 차트로 확인 가능

## 🎯 자산 탭 — 순자산 목표 + 달성률 추가

**어디서**: 자산 탭 맨 위 (가장 먼저 보이는 카드)

**뭐가 생겼나**
- 목표 금액 입력 후 "저장" 버튼 (또는 Enter)
- 즉시 표시: `목표 10억 → 현재 67% 달성`
- 컬러 프로그레스바
  - 0~50%: 파란색
  - 50~99%: 노란색
  - 100% 이상: 초록색 + 🎉 달성 완료 표시
- 하단에 "현재 얼마 / 목표까지 얼마 남음" 안내

**사용법**
1. 자산 탭 맨 위 금액 칸에 목표 순자산 입력 (예: `1000000000` = 10억)
2. 저장 클릭 → 바로 달성률 확인
