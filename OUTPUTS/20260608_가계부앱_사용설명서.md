# 가계부 앱 사용 설명서

> 브라우저에서 바로 쓰는 개인 가계부. 설치 불필요, 데이터는 내 기기에만 저장됩니다.
> 마지막 업데이트: 2026-06-08

---

## 시작하기

### 여는 방법 (두 가지 중 하나)
| 방법 | 설명 |
|------|------|
| **파일 방식** | 받은 `가계부_공유용.html` 파일을 저장 → 크롬으로 열기 |
| **URL 방식** | 링크를 북마크에 저장해두고 사용 |

> 💡 **크롬 브라우저 권장.** 데이터는 같은 브라우저에서 열어야 유지됩니다.
> 파일 방식은 파일을 삭제하지 말고 항상 같은 파일로 열어야 해요.

| 탭 | 이름 | 핵심 기능 |
|----|------|---------|
| 1️⃣ | 내역 | 수입·지출·저축 기록 |

| 6️⃣ | 구독 | 구독 서비스 자동 등록 |

## 1️⃣ 내역 탭

### 기록 유형 3가지
| 유형 | 색 | 예시 |
|------|----|------|
| ↑ 수입 | 초록 | 급여, 부동산 수입, 투자 수익 |
| ↓ 지출 | 빨강 | 식비, 관리비, 의료비 |
| ↓ 저축 | 파랑 | 적금, 펀드·ETF, 부채상환 |

> 저축과 지출은 둘 다 잔액에서 빠지지만 **저축은 분석탭에서 별도로 집계**됩니다.

### 내역 입력 방법
1. 유형(수입/지출/저축) 선택
2. 날짜, 분류(그룹→항목), 금액, 메모(선택) 입력
3. **등록** 버튼 클릭

### 저축 — 부채상환 기록
- 저축 유형 선택 후 그룹에서 **💸 부채상환** 선택
- 항목 목록에 자산 탭에 등록된 부채명이 자동으로 뜸
- 기록하면 자산 탭의 해당 부채 잔액이 **자동으로 감소**

### 카카오페이 내역 자동 입력
- 카카오페이 알림 문자를 복사해서 붙여넣기
- 날짜·금액·가맹점이 자동으로 채워짐

### 월 이동
- 상단 ◀ ▶ 버튼으로 지난달·다음달 내역 확인 가능

### 내역 삭제
- 각 항목 오른쪽 🗑️ 버튼 클릭

## 2️⃣ 분석 탭

### 보여주는 내용
- **이번 달 요약**: 총 수입 / 총 지출 / 총 저축 / 잔액
- **저축률**: 수입 대비 저축 비율 (목표 저축률과 비교)
- **그룹별 분석**: 고정·변동·교육·비정기 그룹별 예산 대비 실적
  - 예산 대비 몇 % 썼는지 + 자동 코멘트
- **수입 대비 비중**: 각 그룹이 수입의 몇 %인지 표시

### 월 이동
- ◀ ▶ 버튼으로 지난달 분석도 확인 가능

---

## 3️⃣ 카테고리 탭

### 예산 진행바
- 고정·변동·교육·비정기·저축 그룹별로 예산 대비 실제 사용액 막대 표시
- 막대 색: 여유(초록) → 주의(노랑) → 초과(빨강)

### 도넛 차트
- 이번 달 지출 항목별 비율을 도넛 차트로 시각화

### 고정지출 체크박스
- 월세, 관리비 등 정기 지출 항목 체크
- 클릭하면 내역 탭에 자동 등록됨 (매달 수동 입력 불필요)

### 월 이동
- 상단 월 선택으로 다른 달 카테고리 확인 가능

## 4️⃣ 연예산 탭

### 하는 일
연간 예산을 미리 짜두면 월별 예산이 자동 계산됩니다.

### 수식 입력 지원
| 입력 예시 | 계산 결과 |
|----------|---------|
| `22만` | 220,000원 |
| `22.5만` | 225,000원 |
| `30*12` | 360,000원 |
| `150만*6` | 9,000,000원 |

### 예산 항목 구성
- **수입**: 급여, 부동산 수입 등 연간 수입원별 입력
- **고정지출**: 월세·관리비·통신비·보험료 등
- **변동지출**: 식비·교통비·의료비 등
- **교육비**: 학원비·육아비 등
- **비정기지출**: 경조사·여행·전자제품 등
- **저축·투자**: 적금·펀드·연금 등
- **부채상환 계획**: 자산 탭 부채와 연동 (현재 잔액 → 상환 후 잔액 자동 계산)

### 요약 박스
- `수입 − 지출 − 저축 − 상환 = 가용잔액` 한눈에 확인

### 연진행 현황 (탭 하단)
- 현재까지 실제 지출이 연간 예산의 몇 %인지 항목별 진행바로 표시

## 5️⃣ 자산 탭

### 🎯 순자산 목표 (탭 맨 위)
1. 금액 칸에 목표 순자산 입력 (예: `1000000000` = 10억)
2. **저장** 버튼 클릭 (또는 Enter)
3. 달성률 프로그레스바 + "목표 X억 → 현재 N% 달성" 자동 표시

| 달성률 | 색상 |
|--------|------|
| 0~49% | 파란색 |
| 50~99% | 노란색 |
| 100% 이상 | 초록색 🎉 |

### 📈 순자산 추이 차트
- **"이번 달 기록"** 버튼: 현재 자산−부채를 계산해서 이번 달 순자산으로 저장
- 같은 달에 다시 누르면 최신 값으로 덮어씀
- 2개월 이상 쌓이면 꺾은선 차트 자동 표시
- 기록 목록 오른쪽 ✕로 특정 달 삭제 가능
- **매월 1회** 눌러두면 내 순자산 변화 흐름을 한눈에 볼 수 있어요

### 📊 순자산 요약 카드
- 순자산(자산 − 부채) 합계
- 자산 유형별 금액 및 비중 칩(chip)으로 표시

### 💰 자산 목록
자산 유형 6가지:

| 유형 | 예시 |
|------|------|
| 💵 현금·예금 | 은행 통장, 예금 |
| 🏦 적금 | 정기적금, 목돈 마련 |
| 📈 주식·ETF | 주식, 펀드, ETF |
| 🏠 부동산 | 집, 토지, 건물 시세 |
| 🏛️ 연금·퇴직금 | 국민연금, 퇴직연금 |
| 💼 기타 | 자동차, 귀금속 등 |

- **+ 추가** 버튼으로 항목 추가
- 항목명·유형·금액 입력 후 자동 저장

### 💸 부채 목록
- 전세대출, 주택담보대출, 마이너스통장, 카드론 등 등록
- **내역 탭에서 부채상환을 기록하면 잔액이 자동으로 줄어들어요**
  - 단, 부채명을 자산 탭과 똑같이 써야 연동됨
- 이자는 내역 탭 지출 → 고정 → 대출이자로 별도 기록

## 6️⃣ 구독 탭

### 등록 방법
서비스명·금액·결제일·주기(월간/3개월/6개월/연간) 입력 후 저장

### 자동 기능
- 매달 1일, 이번 달 결제되는 구독이 **내역 탭에 자동 등록**됨
- 결제일 7일 이내 항목은 알림 표시

## 데이터 관리

### 백업하기 (내보내기)
내역 탭 하단 → **JSON 내보내기** → 파일 저장

> 💡 한 달에 한 번 정도 백업해두는 걸 권장해요.

### 복원하기 (가져오기)
내역 탭 하단 → **JSON 가져오기** → 백업 파일 선택

> ⚠️ 앱을 지우거나 브라우저 데이터(캐시)를 삭제하면 내역이 사라집니다.

## 자주 묻는 질문

**Q. 앱을 다른 기기에서도 쓸 수 있나요?**
A. URL 방식이면 가능하지만 데이터는 기기별로 따로 저장됩니다. 이전하려면 백업 파일을 새 기기에서 가져오기 하세요.

**Q. 부채상환을 기록했는데 잔액이 안 줄어요.**
A. 내역 탭에서 저축 → 💸 부채상환 → 항목을 선택할 때, 자산 탭에 등록된 부채명과 **정확히 같은 이름**이어야 연동됩니다.

**Q. 저축이 잔액에서 빠지는 게 맞나요?**
A. 네, 저축도 통장에서 나가는 돈이니 잔액에서 차감됩니다. 다만 분석 탭에서 지출과 별도로 집계해서 저축률을 계산해줍니다.

**Q. 수식 입력이 안 돼요.**
A. 연예산 탭의 금액 칸에서만 수식이 됩니다. `22만`, `30*12` 형식으로 입력하세요.
