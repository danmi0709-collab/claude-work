# MarkItDown 설치 완료

## 뭘 설치했나
- **MarkItDown**: 마이크로소프트가 만든 무료 도구. PDF·워드·파워포인트·엑셀 파일을 마크다운(.md, 순수 텍스트) 파일로 바꿔줌.
- 버전: `markitdown 0.1.7` (부가 기능 전부 포함하는 `[all]` 옵션으로 설치)
- 설치 위치: 이 작업 환경(컨테이너)의 파이썬. 파이썬은 이미 있어서 새로 설치 안 함(3.11.15).

## 어떻게 확인하나
아래 명령어를 터미널(명령어 입력하는 검은 창)에 치면 버전이 뜸.
```
markitdown --version
```
→ `markitdown 0.1.7` 이렇게 나오면 정상.

## 재설치가 필요할 때
이 컨테이너(작업 공간)는 세션이 끝나면 사라지는 임시 환경이라, 다음에 새 세션에서 또 필요하면 아래 한 줄로 재설치 가능하도록 목록을 남겨둠.
```
pip install -r requirements-markitdown.txt
```
파일 위치: `requirements-markitdown.txt` (리포 최상위)

## 써본 결과
간단한 HTML 파일로 변환 테스트 완료 — 제목·문단이 깨끗한 마크다운으로 잘 나옴. 실제 PDF/워드/엑셀 파일로도 같은 방식으로 쓰면 됨.

## 사용법 (파일 하나 변환)
```
markitdown 파일이름.pdf > 파일이름.md
```
- 워드(.docx), 파워포인트(.pptx), 엑셀(.xlsx)도 확장자만 바꿔서 똑같이 쓰면 됨.
- 참고: 이 컨테이너엔 ffmpeg(영상·음성 처리 프로그램)가 없어서, 유튜브 영상·음성 파일 변환은 지금 환경에선 안 됨. PDF·워드·파워포인트·엑셀 변환은 문제없음.

## 참고: 노션 가이드와 다른 점
읽은 노션 가이드(https://possible-timpani-b05.notion.site/MarkItDown-...)는 **클로드 데스크탑 앱 + 내 컴퓨터(로컬)** 기준 설명이었음. 지금 이 작업은 로컬 컴퓨터가 아니라 클라우드 작업 환경(웹 세션)이라, "Claude 데스크탑 앱 설치, Code 탭에서 폴더 선택" 같은 단계는 해당 안 되고, 핵심인 "파이썬 확인 → markitdown 패키지 설치" 부분만 이 환경에 맞게 그대로 실행함.
내 컴퓨터(윈도우)에서도 똑같이 쓰고 싶으면, 노션 가이드 4~6번대로 클로드 데스크탑 앱을 따로 설치해야 함 — 그건 이 작업 환경과 별개임.
