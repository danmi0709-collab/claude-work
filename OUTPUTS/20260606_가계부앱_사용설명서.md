# 가계부 앱 사용 설명서

> 브라우저에서 바로 쓰는 개인 가계부. 데이터는 내 기기에만 저장됩니다.

---

## 시작하기

- **파일 방식**: 받은 `가계부_공유용.html` 파일을 저장 → 크롬/사파리로 열기
- **URL 방식**: 링크를 북마크에 저장해두고 사용

> 💡 크롬 브라우저 권장. 데이터는 같은 브라우저에서 열어야 유지됩니다.

---

## 탭별 기능

### 1️⃣ 내역 탭
- 수입/지출 입력: 날짜 · 카테고리 · 금액 · 메모
- 월 선택해서 해당 월 내역 조회
- 항목 옆 🗑️ 버튼으로 삭제
- 카카오페이 내역 붙여넣기 자동 파싱 지원

### 2️⃣ 분석 탭
- 이번 달 저축률, 그룹별 예산 대비 실적 코멘트
- ◀ ▶ 버튼으로 지난달 분석도 확인 가능

### 3️⃣ 카테고리 탭
- 고정/변동/교육/비정기 그룹별 예산바
- 도넛 차트로 지출 비율 시각화
- 고정지출 체크박스 (클릭하면 내역 자동 등록)

### 4️⃣ 연예산 탭
- 연간 수입/지출 예산 항목별 입력
- 수식 지원: `22만`, `22.5만`, `30*12` 등
- 고정 / 변동 / 교육 / 비정기 4개 그룹으로 분류

### 5️⃣ 연진행 탭
- 올해 예산 대비 실제 지출 현황 (항목별 진행바)

### 6️⃣ 구독 탭
- 구독 서비스 등록 (서비스명 · 금액 · 결제일 · 주기)
- 매달 1일 자동으로 내역 탭에 등록
- 7일 이내 결제 예정 알림
- 월간 / 3개월 / 6개월 / 연간 주기 지원

---

## 데이터 관리

### 백업 (내보내기)
내역 탭 하단 → **JSON 내보내기** → 파일 저장

### 복원 (가져오기)
내역 탭 하단 → **JSON 가져오기** → 백업 파일 선택

> ⚠️ 앱을 지우거나 브라우저 데이터를 삭제하면 내역이 사라집니다.
> 정기적으로 백업해두세요!
