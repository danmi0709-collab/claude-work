# 💬 가계부 앱 카톡 공유 문구

## 🔥 버전 1 — 찐친한테 보내는 스타일

```
야 이거 진짜 대박임 ㅋㅋ

나 요즘 이 앱으로 가계부 쓰는데
설치도 필요 없고 그냥 링크 누르면 바로 됨
근데 기능이 진짜 많음? 지출 분석에 자산 관리까지 됨

👇 그냥 눌러봐

https://danmi0709-collab.github.io/gagyebu/share

📲 폰 바탕화면에 저장해두면 앱이랑 똑같이 씀
(아이폰은 사파리로 열어서 공유버튼 → 홈화면에 추가)
```

---

## 💌 버전 2 — 지인/가족한테 보내는 스타일

```
가계부 앱 하나 공유할게요 😊

설치 없이 브라우저에서 바로 쓰는 무료 앱인데
수입·지출 기록, 카테고리 분석, 자산 관리까지 다 돼요
광고도 없고 내 데이터는 내 폰에만 저장돼요!

▶ 링크: https://danmi0709-collab.github.io/gagyebu/share

📱 홈화면에 저장하면 앱처럼 쓸 수 있어요
• 안드로이드: 크롬 접속 → 점 세 개 → 홈화면에 추가
• 아이폰: 사파리 접속 → 공유버튼(□↑) → 홈화면에 추가
```
