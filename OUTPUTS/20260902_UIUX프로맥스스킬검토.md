**지금 이 원격 세션에서는 대신 설치가 불가능함.** 코드 자체는 위험 신호 없지만, 별 개수(별점, star 표시 지표)는 조작 의심.

1. **깃허브(GitHub, 코드 저장 공간) 저장소**: `nextlevelbuilder/ui-ux-pro-max-skill`
   - 별(star) 123,939개, 포크 13,261개 — 실제 존재하는 숫자 맞음
   - 그런데 저장소 **생성일이 2025-11-30** (3개월도 안 됨). 3개월 만에 이 정도 별 개수가 붙는 건 정상적 성장 속도가 아님 → 봇으로 별 개수를 부풀리는 "가짜 별" 수법일 가능성 높음
2. **코드 내용 직접 검사** (스크립트, 설치 파일 전부 클론해서 확인)
   - 외부 서버로 정보 빼돌리는 코드, 숨겨진 실행 코드, 수상한 자동 실행(postinstall) 스크립트 → 없음
   - 폰트, 색상표, UI 스타일 데이터베이스 등 마케팅 이미지에 나온 내용과 실제 파일 구성이 대체로 일치함
   - MIT 라이선스, 정상적인 플러그인 설정 파일(`.claude-plugin/marketplace.json`) 구조

## 왜 제가 직접 설치를 못 해드리는지
`/plugin marketplace add`, `/plugin install` 이 두 명령어는 한나 님이 실제로 쓰는 로컬 클로드 코드(컴퓨터에 설치된 프로그램) 터미널에서 직접 입력해야 하는 명령어예요. 지금 이건 원격(클라우드) 세션이라 이 두 줄을 대신 실행해도 한나 님 컴퓨터의 클로드 코드에는 반영이 안 돼요.

## 그래서 어떻게 하면 되나
설치를 원하시면, 평소 쓰시는 컴퓨터의 클로드 코드 터미널에 아래 두 줄을 직접 입력하시면 돼요.
```
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill
```
코드 자체는 문제 없어 보이지만, 별 개수 조작 의심은 여전히 남아 있어서 "이 정도면 신뢰해도 되는 제작자다"라고 100% 보장은 못 해드려요. 설치 여부는 한나 님 판단으로 최종 결정하시는 게 맞아요.
